# 🎬 K-Drama Directory

A modern, responsive web application that displays a curated list of top-rated Korean Dramas. This project was built using vanilla JavaScript to dynamically render content into the DOM, featuring a sleek UI with hover animations and glassmorphism effects.

## ✨ Features
* **Dynamic Rendering**: Dramas are loaded from a JavaScript array and injected into the DOM automatically.
* **Random Emoji Generator**: Each drama card is dynamically assigned a random emoji from a predefined set.
* **Responsive Grid Layout**: Fully responsive design using CSS Grid to ensure it looks great on desktop, tablet, and mobile.
* **Modern UI**: Implements CSS hover transitions, semi-transparent backgrounds (`rgba`), and backdrop filters (`blur`) for a glass-like aesthetic.
* **Auto-Counting**: Automatically calculates and displays the total number of dramas available in the directory.

## 🛠️ Technologies Used
* **HTML5**: Semantic structure.
* **CSS3**: Custom styling, CSS Grid, Gradients, and Transitions.
* **Vanilla JavaScript (ES6)**: DOM manipulation, array iteration (`forEach`), template literals, and random number generation.

## 🚀 Getting Started

Since this is a front-end-only project with no external dependencies, running it is incredibly simple.

### Prerequisites
* A modern web browser (Chrome, Firefox, Safari, Edge).
